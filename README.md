# PersonelBlog

This is the Test task solution for the Node developer.js
Requirements:
•	You need to develop a frontend and backend (REST API) for your personal blog
•	The application is a page where any authorized users can make recordings.
1. It is necessary to implement user registration and authorization, as well as verification of the JWT token when making entries on the page
2. The blog entry contains:
    a. Date of recording
    b. Message: can contain both text and media (pictures or videos)
    c. The author of the message
3. The author of the post can edit or delete the post.
4. It is necessary to deploy a server for public access (you can use heroku or any other free hosting)
5. It is necessary to write documentation for the endpoints (manually or generate it from the code)

# I used:
- A relational database must be used (Postgresql)
- Express js/fastify
- ORM
- React
- Typescript
- Docker
- Eslint
- Swagger 
- libraries for jwt authorization
- CSS frameworks
- Material Ui, Ant Design or other Ui libraries
